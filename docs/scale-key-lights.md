# 调式琴键灯：SLOOP 2.8.4 扩展

这个 fork 在原版 2.8.4 上增加 **KEYS = SCALE**。它帮助你辨认当前调式内的键，不改变琴键发出的音，也不修改录好的音符。

## 开启一次，以后自动跟随

1. 按住 **HOME** 约 0.7 秒进入菜单。
2. 转 **SELECT** 找到 **LIGHTS** 分类。
3. 转 **KNOB 2**，把 **KEYS** 设为 **SCALE**，位于 ALL KEYS 后面。如果 LIGHTS 原来关闭，会自动设为 LOW；用 KNOB 1 调 LOW / MID / HIGH。
4. 按 OCT− 退出菜单，回到普通演奏页；选一条合成轨 1–3。
5. 短按 **SEL**，转 SELECT 找 **SEL** 页：**KNOB 1 / ROOT** 选根音，**KNOB 2 / SCL** 选音阶。这两个参数只改当前轨，灯光会立即跟随。

亮度从低到高：调内音 → 根音 → 按下或正在发声的音。最后一项包括序列播放，即使旧的 NOTES 灯选项是 OFF，SCALE 模式下仍会显示。

SCALE2 修正了第一版提示过暗的问题：调内键改用完整扫描时段调光。LIGHTS 的 LOW / MID / HIGH 分别约为正常亮键点亮时间的 25% / 37.5% / 50%；根音为 50% / 62.5% / 75%，弹奏音保持全亮。建议从 MID 开始。面板标签和其他功能层保留原来的亮度方式。

设置随设备保存；旧的 OFF / C KEYS / WHITE KEYS / ALL KEYS 均保留。升级不会强制覆盖你原来的灯光偏好，需要手动选一次 SCALE。LIGHTS OFF 会隐藏调式提示。回刷不认识 SCALE 的旧固件时，该选项按 OFF 读取。

## C 大调与 G 大调怎么试

先保留正常半音键盘：在 **SEL 页**把 **QNT = OFF**、**CHORD = OFF**，八度和移调设回 0。

- **ROOT C、SCL MAJ**：C、D、E、F、G、A、B 亮，C 更亮。
- **ROOT G、SCL MAJ**：G、A、B、C、D、E、F♯ 亮。F♯ 黑键亮，F 白键不亮，G 更亮。
- **ROOT D、SCL MIN**：D、E、F、G、A、B♭、C 亮，D 更亮。

转 ALGORITHM 切轨，提示跟随新轨道自己的 ROOT / SCL。按住 SEL 再按琴键、或按住 SEL 转 KNOB 2，是原有的全体合成轨改根音／音阶操作；也会被灯光跟随。

## 怎样用灯找和弦

灯只表示音阶成员，不会自动判断“同时按这几个音是否适合当前和弦”。在 C 大调里，可以沿亮着的音阶“隔一个音取一个音”组成三和弦：

- C：C–E–G
- Dm：D–F–A
- Em：E–G–B
- F：F–A–C
- G：G–B–D
- Am：A–C–E
- Bdim：B–D–F

先试 C → Am → F → G；想用一个手指弹整组和弦，可以另开原有 CHORD 功能。SCALE 灯本身不会替你开和弦模式。

## 与其他模式配合

- 普通半音键盘：亮的是实际调内琴键位置，保留黑白键原来的音程关系。
- 已开启 SNAP：每个键可能都被吸附到调内，因此可能全部亮；这不是坏了。
- 已开启 WHITE / CHORD：按现有映射后的音高提示；黑键是静音键或和弦修饰键，不用调内灯把它们误画成可弹音。
- 移调与八度：按键实际会发出的音高参与判断；移调后，亮的物理位置可能移动。CHORD 配 CHR 时沿用原有的小调回退规则。
- 鼓轨、GM KIT 和可选 SLICE 的鼓垫映射不显示调式提示。
- 进入 SEQ、FX、GLO、SEL 等功能层后，让位给该层原来的步进、效果和操作灯；松开后恢复。

## 获取固件与验证

固件标签为 **2.8.4-SCALE2**，基于上游 `v2.8.4`，并非上游的新正式发布。见 [构建说明](../BUILDING.md#fork-builds-in-github-actions)。安装前用官方网页编辑器导出完整 Backup；安装包里不含你的音乐与样本。

专用测试覆盖 16 个音阶、12 个根音、全部八度／移调范围共 65,856 组普通键盘组合，以及映射键盘、不同轨道、灯光优先级、功能层、旧设置与持久化。主机测试不等于已经肉眼检查实体设备的亮度。
